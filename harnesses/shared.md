# SHARED GSA LOCAL RULES

- Treat live project files as source truth and registry state as execution truth.
- Preserve unrelated user-owned changes.
- Read current targets before writing.
- Stay inside the canonical project root and current approved scope.
- A denied boundary is not a puzzle; never route around it.
- Discover real project build/test/lint/typecheck commands before verification.
- Verification is evidence, not ceremony. Never manufacture PASS.
- Tests alone do not prove the goal; compare evidence against acceptance criteria.
- Keep context minimum-sufficient and bind reviews to exact revisions.
- Do not persist hidden reasoning or chain-of-thought.
